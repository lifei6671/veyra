# P7 数据与发布收尾

[任务总表](IMPLEMENTATION_PHASES.md) · [当前交接](SESSION.md) · [方案](../openbox-rust-gpui-implementation-plan.md)

**阶段前置**：OBG-P6-05。目标是可恢复的数据操作、可验证的 GitHub 安装包和完整验收记录。发布准备完成与实际发布是不同结果。

<a id="obg-p7-01"></a>
## OBG-P7-01 备份、预览与原子导入

**类型**：数据与 UI；**额外前置**：无。**依据/范围**：方案 §8.8、§12；core backup/importer、后端数据设置；API 22–23。

**执行与交付**：新备份格式与 OpenBox/旧 Veyra 独立 importer、原生保存/读取、内容预览、订阅 replace/append、引用 ID 重映射和可选刷新。

**验收**：

- [ ] 预览/校验失败不写入；整体提交原子，append 重映射所有相关引用，replace 创建新 epoch。
- [ ] 导入后用新 ID 刷新；刷新部分失败不撤销已导入静态配置；旧任务不能写回新状态。
- [ ] 不包含 pending、进程身份、运行缓存或可直接启动 manifest；业务备份与脱敏诊断明确区分。
- [ ] 主题/背景/配置刷新无需浏览器 reload；预览、选择、取消、错误和浅深色通过验收。

<a id="obg-p7-02"></a>
## OBG-P7-02 诊断导出与恢复出厂

**类型**：维护服务与 UI；**额外前置**：OBG-P7-01。**依据/范围**：方案 §8.8、§13；core diagnostics/maintenance、后端数据设置；API 20、24。

**执行与交付**：定义诊断 schema、脱敏导出、版本/操作/能力和恢复记录摘要；恢复出厂 10 秒倒计时及停止→网络恢复→删除→首次使用流程。

**验收**：

- [ ] 诊断不含可用密码/token/URL 凭据/私钥；结果不完整时明确说明。
- [ ] 倒计时/确认可操作；停止或恢复网络失败时终止删除并保留归属材料。
- [ ] 成功重置仅删除本应用数据/缓存/token，旧分享入口失效，进入新的状态 epoch。
- [ ] 导出/重置成功和失败的真实操作与 界面检查通过，不在用户正式数据上做破坏性验证。

<a id="obg-p7-03"></a>
## OBG-P7-03 GitHub 包构建与手动升级演练

**类型**：发布工程；**额外前置**：OBG-P7-01、OBG-P7-02。**依据/范围**：方案 §8.8、§14、§16；构建脚本/CI、应用资源与安装包。

**执行与交付**：绑定源码/锁文件/应用/helper/内核/资源版本；实现已选架构的可复现构建、无发布签名安装包与摘要；检查最低 ad-hoc 运行要求，执行手动更新成功/失败/回退。

**验收**：

- [ ] 包内容、架构、最低运行签名状态与版本清单可对应；没有 Developer ID/公证也可按说明从真实下载包打开，不关闭系统保护。
- [ ] 从已知旧版本按选定路径升级；失败保留可恢复版本，运行文件与网络清理失败不强行覆盖。
- [ ] 新安装/升级后配置、选择、必要缓存和 helper 版本符合预期；旧 schema 回退边界明确。
- [ ] 仅使用验证后的候选包；上传、发布或修改生产渠道需当前明确授权。

<a id="obg-p7-04"></a>
## OBG-P7-04 全范围追踪与交互验收

**类型**：完整性验收；**额外前置**：OBG-P7-01、OBG-P7-02。**依据/范围**：方案 §16–18；本清单覆盖表、六主页面/九设置分类及现有测试。

**执行与交付**：逐项核对接口去向、页面入口、19 个最低场景、能力差异和引用；补充缺失证据，执行与最终改动相关的回归和独立 Review。

**验收**：

- [ ] 77 个方法、4 个流通道、六主页面和九分类都有实现证据或明确批准的不迁移理由。
- [ ] 方案 §16.2 的 19 个场景全部有适用性、结果与证据；N/A 不冒充 PASS。
- [ ] 页面/弹窗的操作、加载/空/错误/忙碌、浅深色和窗口尺寸验收完整，实际操作与截图结果可追溯，不要求旧批准文件。
- [ ] 未实现的 DNS/路由器等能力在发布说明准确披露，无占位按钮被计算为等价完成。

- [ ] 所有首期必需 Task 完成，剩余项只属于有批准记录的后续范围；没有未解决的本次回归。
- [ ] SESSION 标为“macOS 候选版验收完成”，包含发布包和验收链接；实际发布状态另行记录。
