**里程碑范围**：目标是主页面基础能力与有来源的观测；高级 Group/Chain、Routing/Terminal 与 DNS 在 P4/P5 增量集成，不将基础验收写成全量完成。阶段不作统一 Gate；以下各卡的显式依赖独立决定 READY。

**2026-10-08 分期适用范围**：未完成卡遵循[唯一调度政策](DEVELOPMENT_WORKFLOW.md#delivery-order-20261008)。P3-01 必须前期实现实际 Observation 采集/事件/实例隔离服务；P3 连接操作、日志筛选/导出服务、统计查询/测速等真实业务也在各自卡完成，使用受控 loopback/自有资源做生产服务的局部定向集成，不能只有 DTO/Mock/静态视图就 DONE。适用偏好、SQLite 统计/延迟历史、容量/保留配置真实保存与重建回读；纯实时数据不强迫持久化，真实来源缺失时显示未知/不可用，不代替应有服务实现。UI 绑定实际服务结果并验证加载/空/失败/忙碌及 150% 浅色局部操作。P3-08 仅补实际内核、跨页/容量/长时/性能组合和其它主题/缩放，P7-04 统一 E2E；原本地业务操作/定向集成不移交组合卡。无授权的具体 Native 步骤记 NOT_RUN/原因/承接卡，接口/状态/安全控制仍实现；原依赖/验收覆盖保留，系统代理/TUN 不新增为前置。

<a id="obg-p3-01"></a>
## OBG-P3-01 单一观测采集与有界事件

**类型**：实时服务；**依赖**：OBG-P2-03、OBG-P0-07。**依据/范围**：方案 §10.1–10.2；core observation/controller；四类 WS 通道。

**泳道 / 写范围**：Observation；observation/controller 采集/事件；RuntimeEvent 公共 DTO 交 owner。

**执行与交付**：每实例一组采集，归一化 traffic/memory/connections/logs；实例隔离、快照与事件分发、有界慢订阅处理；以实际观测元数据提供 client discovery/已知终端投影，供 P4-05B 的 `clients.observed()` 或等价读取使用，不依赖 Connections 页面实现。

**验收**：

- [x] 多页面不重复建立同类内核采集；换实例后旧帧丢弃。
- [x] 速率/累计/重置按 P0 口径处理，不再错误差分区间流量。
- [x] 已知终端投影仅使用当前实例可观察身份/来源，未知字段不猜测；切换实例丢弃旧终端信息。
- [x] 断流、未知内存和慢订阅缺口明确反馈，不显示伪零或阻塞控制命令。

**当前状态：DONE（本组合分支）**。原四项生产 Service/WS 验收保留，本轮已补正式 Runtime Ready/Stop/Replace/handoff 接线与锁定真实内核隔离验证，最终独立 Review 通过。Observation owner/本卡预约释放，P2-06 总卡仍 DOING及原owner保留；公共 DTO、collector语义和显式依赖不变。见[接线与最终审查](P2-06-observation-integration.md)及[历史交付](P3-01-acceptance.md)。
