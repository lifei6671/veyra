# P3 观测与主页面

[任务总表](IMPLEMENTATION_PHASES.md) · [当前交接](SESSION.md) · [方案](../openbox-rust-gpui-implementation-plan.md)

**阶段前置**：OBG-P2-09。目标是补齐六主页面的主体交互与有来源的观测；高级分流/DNS 操作继续在所属阶段完成。

<a id="obg-p3-01"></a>
## OBG-P3-01 单一观测采集与有界事件

**类型**：实时服务；**额外前置**：OBG-P0-07。**依据/范围**：方案 §10.1–10.2；core observation/controller；四类 WS 通道。

**执行与交付**：每实例一组采集，归一化 traffic/memory/connections/logs；实例隔离、快照与事件分发、有界慢订阅处理。

**验收**：

- [ ] 多页面不重复建立同类内核采集；换实例后旧帧丢弃。
- [ ] 速率/累计/重置按 P0 口径处理，不再错误差分区间流量。
- [ ] 断流、未知内存和慢订阅缺口明确反馈，不显示伪零或阻塞控制命令。

<a id="obg-p3-02"></a>
## OBG-P3-02 连接列表与详情

**类型**：UI 与连接操作；**额外前置**：OBG-P3-01。**依据/范围**：方案 §2.2、§3；连接页、core connections/GeoIp；API 36–37。

**执行与交付**：活动/历史虚拟表、搜索/排序/多列分组/列偏好、详情、断开、IP 信息与关联选择。

**验收**：

- [ ] 流式更新中稳定行 ID、选中和详情不串对象；活动/历史去重，历史初期上限 100。
- [ ] 断开单条/全部只作用请求时的实例；连接结束后可查看最后记录。
- [ ] 筛选/布局保存、空/错误/忙碌状态、5000 条样本下操作和浅深色通过验收。

<a id="obg-p3-03"></a>
## OBG-P3-03 日志筛选、暂停与导出

**类型**：UI 与日志服务；**额外前置**：OBG-P3-01。**依据/范围**：方案 §10.1；core logs、日志页。

**执行与交付**：Runtime、订阅队列与 UI 缓冲按方案分层；级别/类别/正则、暂停、清空、文本选择和原生导出。

**验收**：

- [ ] 暂停只影响该 UI 的接收，恢复不补入暂停日志；清空不误删运行诊断。
- [ ] 1000 条 UI 缓冲、慢订阅溢出与导出范围有明确行为；无界队列不会累积。
- [ ] 非法正则可修正，敏感字段脱敏，实际操作及浅深色验收通过。

<a id="obg-p3-04"></a>
## OBG-P3-04 统计存储与容量

**类型**：数据；**额外前置**：OBG-P3-01。**依据/范围**：方案 §10.3；core storage/traffic 与 SQLite schema。

**执行与交付**：单 writer、有界批提交、关联时间桶及历史压缩；测量后固定桶宽、索引、保留期和容量；同口径记录可归属与未归属数据。

**验收**：

- [ ] 只存实际维度组合；重连/重复快照不重复累计，维度变化按增量归属。
- [ ] 同实例/口径/对齐窗口才能对账；不通过截断负差值制造恒等式。
- [ ] 高基数样本的每日空间、写入/下钻成本有实测；容量清理报告缩短范围，写入时不丢 TopN 以外明细。
- [ ] UTC、时区、跨日/夏令时、保留期和未提交统计损失边界有定向验证。

<a id="obg-p3-05"></a>
## OBG-P3-05 概览、站点测速与图表

**类型**：UI 与延迟历史；**额外前置**：OBG-P3-01、OBG-P3-04。**依据/范围**：方案 §2.2、§9–10；概览页、core latency；API 38–39。

**执行与交付**：实时指标、站点测速、历史曲线、图表选择/tooltip；视觉刷新与采样分开。

**验收**：

- [ ] 图表单位/时间轴与来源一致，断流保留未知标识；不拿 GUI 内存充内核内存。
- [ ] 站点结果按目标合并，取消/部分失败可解释；历史重启后可读。
- [ ] 图表操作、空/错误/忙碌、浅深色和缩放后可读性通过验收。

<a id="obg-p3-06"></a>
## OBG-P3-06 历史流量、下钻与存储设置

**类型**：查询与 UI；**额外前置**：OBG-P3-04、OBG-P3-05。**依据/范围**：方案 §6.4、§10.3；core traffic 查询、概览下钻、后端保留周期；API 21、40–42。

**执行与交付**：月/日/小时查询、direct 开关、节点/域名/终端关联下钻、截断信息；独占可中断读连接、请求代次；存储使用量与保留设置。

**验收**：

- [ ] 同一统计可按关联维度继续下钻，超出保留范围/limit 明确报告。
- [ ] 筛选变化使旧结果失效；取消实际停止对应 SQL 或丢弃已结束结果，不中断 writer/其他查询。
- [ ] 保留期输入与清理结果一致，UI 的日期/筛选/加载/错误操作和视觉验收通过。

<a id="obg-p3-07"></a>
## OBG-P3-07 代理完整视图与已加载规则

**类型**：UI；**额外前置**：OBG-P3-01。**依据/范围**：方案 §2.2；ProxiesPage/RulesPage 行为基线；API 25、31，12–13 仅按实际内部需要使用。

**执行与交付**：代理三类视图、搜索/排序/展开、历史延迟和跳转；规则列表与已应用版本；诊断入口预留明确能力状态，真实诊断在 P4 接通。

**验收**：

- [ ] 选择、测速、搜索/排序相互不覆盖，1000 节点样本无持续卡顿。
- [ ] 规则数据来自当前实例，未应用编辑不伪装成已加载规则。
- [ ] 不为无现有业务调用的 controllerConfig/version 增加新页面；可用入口全部真实响应。
- [ ] 三类代理视图、规则列表与必要状态通过浅深色和交互验收。

<a id="obg-p3-08"></a>
## OBG-P3-08 主页面与性能阶段验收

**类型**：阶段验收；**额外前置**：OBG-P3-01、OBG-P3-02、OBG-P3-03、OBG-P3-04、OBG-P3-05、OBG-P3-06、OBG-P3-07。

**执行与交付**：同一 release 构建联动检查六主页面、切页/隐藏状态及容量；按 P0 硬件基线测量方案 §16.3 目标并记录偏差。

**验收**：

- [ ] 1000 节点/5000 活动连接/1000 日志下操作可用，帧时间、筛选和冷启动有实测结果。
- [ ] 长时间观察下缓冲、统计与已关闭连接有界；隐藏窗口降低绘制频率。
- [ ] 各页面真实操作、浅深色和必要尺寸的 检查/实际验收完成；尚在 P4/P5 的高级能力没有误计完成。
