# P4 完整配置能力

[任务总表](IMPLEMENTATION_PHASES.md) · [当前交接](SESSION.md) · [方案](../openbox-rust-gpui-implementation-plan.md)

**阶段前置**：OBG-P3-08。目标是配置编辑、保存、编译、生效和重启恢复形成完整切片。共用 P1/P2 的版本与应用入口。

<a id="obg-p4-01"></a>
## OBG-P4-01 订阅高级设置与自动刷新

**类型**：业务与 UI；**额外前置**：无。**依据/范围**：方案 §8.1；core subscription/scheduler、订阅设置；API 46–48、56–59 的高级语义。

**执行与交付**：重命名、排除/禁用、节点 DNS、多 URL 顺序和重复策略、自动更新时间与刷新反馈；睡眠后合并一次错过的任务。

**验收**：

- [ ] 配置→预览→保存→刷新保持已确认节点身份及用户覆盖，dangling 有提示。
- [ ] 自动刷新仅在应用运行时执行；唤醒不逐次补跑，旧 epoch 下载不落入新快照。
- [ ] 高级字段、错误输入、部分失败、拖拽/排序与浅深色通过实际验收；分享功能单列 P5。

<a id="obg-p4-02"></a>
## OBG-P4-02 静态/动态节点组与编辑器

**类型**：业务与 UI；**额外前置**：OBG-P4-01。**依据/范围**：方案 §8.2；core groups/compiler、出站节点设置；API 43–45。

**执行与交付**：selector/urltest、静态/动态成员、国家分组、图标、拖拽、默认组与成员引用；返回 dropped/dangling 结果。

**验收**：

- [ ] 动态组只使用实际存在且符合条件的节点，排除禁用节点，保留手工顺序与新增成员。
- [ ] 循环/重名/悬空成员可定位；保存失败不丢草稿，合法配置可应用并重启恢复。
- [ ] 编辑弹窗、默认恢复、排序和节点展示通过界面检查；failover 策略由下一任务完成。

<a id="obg-p4-03"></a>
## OBG-P4-03 failover 编排与手动写权

**类型**：运行策略与 UI；**额外前置**：OBG-P4-02。**依据/范围**：方案 §8.2.1；core groups/runtime、主备线路编辑与代理选择。

**执行与交付**：有序 lanes、失败阈值、恢复保持时间、Auto/ManualPin、线路内 manual；复用唯一选择入口和独立 selection_revision。

**验收**：

- [ ] 模拟时钟验证连续失败切备、稳定恢复切主、全失败保留错误；不重写 URLTest。
- [ ] 手动固定使旧探测失效；恢复自动重新探测；迟到结果不覆盖人工选择。
- [ ] 成员变化、进程重启、pending 不确定及保存失败都有一致结果；自动切换不增加 profile revision。
- [ ] 主备编辑、手动固定/恢复自动提示和实际选择经过 界面与最小内核集成验证。

<a id="obg-p4-04"></a>
## OBG-P4-04 规则资源导入、分页与刷新

**类型**：资源服务与 UI；**额外前置**：无。**依据/范围**：方案 §8.3；core rulesets、目标分流的规则集弹窗；API 63–65。

**执行与交付**：受支持 JSON/SRS 资源下载/校验/版本索引、导入明细与 URL 引用、搜索分页和刷新；资源生命周期兼容 last-applied。

**验收**：

- [ ] 导入保留 URL 与数量约束，不支持项报告；旧分页响应不覆盖新筛选。
- [ ] 空/损坏/超时内容不覆盖有效资源；当前或恢复配置引用的版本不被清理。
- [ ] 热加载只有经证实才返回即时生效，否则提示待应用；弹窗操作与浅深色验收通过。

<a id="obg-p4-05"></a>
## OBG-P4-05 目标/终端分流与真实诊断

**类型**：业务与 UI；**额外前置**：OBG-P4-02、OBG-P4-04。**依据/范围**：方案 §8.3、§8.7、§11.5；core routing/compiler/diagnostics、目标/终端分流和规则页；API 32–35、62、66。

**执行与交付**：策略优先级、自定义/兜底、域名/IP/Geo/资源引用、已知终端与来源规则；同一规范化模型用于预览和编译；接通预测与受管入站实测。

**验收**：

- [ ] 顺序、出口与默认恢复可保存、应用并重启恢复；循环/不支持字段明确拒绝应用。
- [ ] macOS 不伪装支持 MAC/内核前旁路/LAN 模拟；导入数据保留并解释限制。
- [ ] 预测与实测分区；GET/HEAD/TCP/TLS 的结论符合实际动作，未唯一关联字段显示不完整。
- [ ] 目标/终端分流与规则诊断的编辑、排序、错误、忙碌及浅深色通过验收。

<a id="obg-p4-06"></a>
## OBG-P4-06 链式代理与候选测试

**类型**：业务与 UI；**额外前置**：OBG-P4-02。**依据/范围**：方案 §8.4；core chain/compiler/latency、链式代理设置；API 49。

**执行与交付**：链接解析、上游选择、detour、启停/排序；连通与出口 IP 在同一候选链上测试，绑定草稿版本。

**验收**：

- [ ] 无效上游、自循环和跨组循环在保存/编译边界拒绝；有效链路可应用。
- [ ] 改字段后旧测试失效，测速和出口 IP 来自同一候选路径；取消/超时清理临时实例。
- [ ] 主实例不被预览测试替换；界面状态、保存/应用区别和浅深色通过验收。

<a id="obg-p4-07"></a>
## OBG-P4-07 配置切片阶段验收

**类型**：阶段验收；**额外前置**：OBG-P4-01、OBG-P4-02、OBG-P4-03、OBG-P4-04、OBG-P4-05、OBG-P4-06。

**执行与交付**：组合订阅→动态组→主备→分流→链路，检查真实保存/应用/恢复；汇总本阶段 UI 与 Compiler 契约证据。

**验收**：

- [ ] 删除/刷新引用和主备手动覆盖没有跨模块写权冲突，相关回归通过。
- [ ] 应用失败保留有效旧运行配置与用户新草稿，恢复状态可解释。
- [ ] 本阶段页面/弹窗的操作、必要状态和视觉检查完整，差异有范围决定。
