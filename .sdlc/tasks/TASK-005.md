# TASK-005：运行观测与托盘恢复边界

## 本次需求

在已验收的 TASK-004 受管运行时之上，建立仅内存保存、默认脱敏的运行观测模型，并将其经固定
Tauri IPC 呈现给主窗口；实现“关闭窗口即隐藏、托盘显式 show/focus 恢复”的桌面生命周期。运行
观测不得写入 `AppState` 或 `state.json`，不得给 UI 暴露 sidecar 命令、路径、PID、Clash API
secret、节点凭据或任意原始日志。

本 Task 不用静态样例或伪实时数据冒充 live runtime。当前仓库尚未有经验证的打包 sidecar、固定
Clash API endpoint/secret 生命周期或实际进程 Port，因此实时连接、流量与 Core Log 的具体来源需要
先经用户确认，才能进入实现。

## 已确认决策

用户已选择候选 A：本 Task 只交付封闭内存 `RuntimeObservationPort`、Mock、固定 IPC 与 Tray
生命周期，不宣称真实连接、流量或 Core Log。真实 sidecar/Clash API 采集仍是后续独立交付单元。
最终端到端验收不得将本 Task 的 Mock 证据当作真实观测证据：在该独立交付完成并获授权后，必须覆盖
经验证 sidecar、固定 loopback Clash API、脱敏 UI 呈现和 Tray 恢复的联合路径；此前该 E2E 项为
`NOT_RUN`。

## Scope

### allow（获得下述契约确认后）

- `src-tauri/src/application/{mod.rs,observability.rs}`：内存 `RuntimeObservationPort`、脱敏
  Snapshot/Delta、订阅生命周期和 Runtime Supervisor 的封闭读侧适配；不持久化运行数据。
- `src-tauri/src/{commands.rs,lib.rs,main.rs,build.rs}`、`src-tauri/permissions/autogenerated/`：固定只读
  observation Snapshot 命令及固定 `show_main_window` 语义和其生成权限；关闭主窗口时只隐藏，不重新
  初始化 AppState、订阅或 sidecar；Windows GUI 启动不得创建控制台窗口。
- `src-tauri/capabilities/default.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、
  `src-tauri/Cargo.lock`：仅为获批 Tauri tray API 与固定命令权限作必要最小变更。
- `src/{App.tsx,lib/observability.ts,lib/observability.test.ts,styles.css}`：连接、流量、日志的
  脱敏只读界面与托盘恢复可观察状态；不把配置原文或 secret 放入前端持久化状态。
- 对应 Rust/TypeScript 单元测试及窗口/托盘行为的最小自动化证据。

### deny

- 未经独立确认的打包或下载 sing-box、真实 sidecar 启动、Clash API 网络访问、任意 endpoint/
  header/secret 输入、真实 Windows System Proxy 改写、TUN/UAC/WFP/Service/Wintun、全系统 PID
  扫描、路由或 DNS 接管。
- 连接历史、流量统计、运行日志或 telemetry 写入 `AppState`、`state.json`、数据库或浏览器
  持久化存储；账号、云同步、分析上报或外部日志服务。
- 任意进程/路径/命令参数、完整生成配置、订阅 token、密码、UUID、私钥、Reality key 或 API secret
  进入 IPC、事件、错误、日志、React/Zustand 持久化状态。

## 子功能

### SF-001：内存运行观测与脱敏边界

**需求：** 定义封闭的 `RuntimeObservationPort` 和内存 Snapshot/Delta，至少描述 capture mode、
sidecar 生命周期、上传/下载速率与累计值、连接数量及分类日志摘要。字段为闭合类型，日志与错误
经过白名单脱敏；不将原始 Core Log、连接目标、进程路径或 credential 复制到观测模型。

**验收：** Mock Port 可证明 Snapshot/Delta 的 revision 单调、无订阅时不积压、重启/窗口恢复不读取
或持久化观测状态，且所有用户可见错误与日志摘要不包含 fixture secret。

**验证：** Rust 单元测试覆盖 revision、速率/累计值、连接增减、日志脱敏、订阅取消与 Runtime
恢复边界；真实 sidecar/Clash API 数据采集为 `NOT_RUN`，直至来源契约获批。

**implementation_status：** IMPLEMENTED
**acceptance_status：** ACCEPTED

### SF-002：固定 IPC 与只读观测界面

**需求：** 仅开放经确认的只读 `runtime_observation_snapshot` 命令和类型化、脱敏的观测增量事件；
前端只显示其 Snapshot/Event，不能传递任意 runtime 参数、读取日志文件或直接访问 loopback API。

**验收：** Capability 仅允许主窗口使用该固定命令；前端测试证明 DTO 校验、加载/错误状态和敏感
字段缺失，后端测试证明未知命令或非法 event 载荷不存在公开入口。

**验证：** Rust/TypeScript 单元测试、Tauri capability 静态检查、`pnpm lint`、`pnpm test` 与
`pnpm build`；真实 sidecar UI 观测为 `NOT_RUN`，直到存在获批的运行时来源。

**implementation_status：** IMPLEMENTED
**acceptance_status：** ACCEPTED

### SF-003：隐藏而非销毁的托盘恢复

**需求：** 主窗口关闭请求默认 hide；固定 Tray 菜单只支持 show/focus 与显式 quit。show/focus 不得
重新读取状态、解析订阅、重启 sidecar 或重建 React Root；高频观测渲染在隐藏状态暂停。

**验收：** 自动化测试或可复现 Windows UI 证据证明 close 后窗口隐藏、Tray show 后相同窗口恢复，
且 Runtime Supervisor 与 AppState 初始化次数不增加；quit 语义只在用户显式选择时触发。

**验证：** Rust 生命周期单元测试、前端测试、获批后使用本机 Windows UI Automation 的 show/hide
证据；真实 sidecar 和 System Proxy 操作不属于该验证。

**implementation_status：** IMPLEMENTED
**acceptance_status：** ACCEPTED

## Task 独立验收

**验收：** 在获批的 IPC、Tray 与观测来源范围内，运行时观测始终内存化且脱敏，主窗口只能经固定
只读命令消费数据，关闭窗口不会破坏应用或 Runtime 状态，Tray 恢复不触发重新初始化；没有任意进程、
路径、endpoint、secret 或真实系统代理入口。

**验证：**

1. 在契约确认后运行 `cargo fmt --manifest-path src-tauri/Cargo.toml -- --check`、
   `cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings`、
   `cargo test --manifest-path src-tauri/Cargo.toml`、`pnpm lint`、`pnpm test`、`pnpm build` 与
   `git diff --check`；
2. 用独立交付审查核对 IPC/Capability 最小化、脱敏、无持久化、Tray 生命周期、Scope 与观测来源
   边界；
3. 分别记录真实 sidecar/Clash API、Windows UI Automation、CI、提交与推送的实际状态，未运行时为
   `NOT_RUN`，不得以 Mock 代替。
4. 最终端到端验收必须在后续已授权的真实 sidecar/Clash API 交付完成后，覆盖其与固定 IPC、脱敏 UI
   和 Tray 恢复的联合路径；TASK-005 的 Mock-only 验证不能关闭该项。
