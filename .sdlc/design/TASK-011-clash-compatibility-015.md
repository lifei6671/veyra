## Contract

1. TLS adds alpn: Vec<String> (default empty, omitted when empty), utls_fingerprint: Option<String> (default None). HY2 adds optional up_mbps/down_mbps and disable_path_mtu_discovery. Existing node/Provider identity, compiler limits and security rules preserved. Explicit known fingerprints validated; malformed lists, zero/overflow rates and conflicting aliases fail. Existing missing-field states read unchanged defaults; V5 stays additive, no file migration or rewrite merely for absent options. Older binaries are not a supported writer for newly extended node settings.
2. Subscription adds skipped_unsupported_nodes:u32 default0/omit0, persisted with successful fetch/import/update and exposed as required skippedNodeCount in SubscriptionSummary DTO. This is a safe count only, no original node names or parameters. 304/metadata-only edit preserves prior count; successful complete-content replacement resets it to new count. UI cards and success notice explicitly say skipped N nodes with unsupported TCP-only multiplex. JSON DTO readers updated atomically with backend.
3. Parser retains rejection of unknown/invalid fields. It canonicalizes exact Clash aliases to existing typed forms: servername/SNI, reality-opts to TLS reality, ALPN/fingerprint; HY2 password/auth, insecure/skip-cert-verify, up/down/up-speed/down-speed/up_mbps, protocol=udp and disable_mtu_discovery. HY2 intrinsic TLS becomes enabled even without explicit tls; explicit tls:false is rejected for TLS-required protocol. benchmark-url and benchmark-timeout are recognized source metadata, validated type and discarded (never executed).
4. Only the explicitly approved skip is introduced: a structurally valid VLESS node with enabled smux.only-tcp:true is SkippedNode::UnsupportedOption; first validate its basic node and all smux fields (known schema/types) so malformed input is still invalid. Other skipped invalid/unknown protocols keep atomic failure. At least one supported node required. No valid parameters of accepted nodes are silently dropped. udp:true is default-equivalent; udp:false remains unsupported/fails. UnsupportedOption drafts are never persisted/compiled. No mux model or TCP/UDP duplicate runtime outbounds are introduced.
5. Application accepts parsed.nodes nonempty plus skipped consisting solely of UnsupportedOption. Clear this explicitly allowed skipped vector before the existing zero-skipped provider replacement function, while retaining its count in same state transaction. Import/update/replacement share the rule. Failure retains all old state; all-skipped errors. Background updates persist count and UI listing displays warning; no automatic runtime switch.
6. Compiler outputs exact TLS ALPN/uTLS fingerprint/HY2 rates/disable_path_mtu_discovery and reconstructs them during final-config validation. Existing Reality without explicit fingerprint retains prior uTLS enabled/no fingerprint bytes. Extra fields must be validated and included in hashes/equality; redacted views retain safe options only. Generated user outbound must pass fixed-core check on synthetic endpoints (no run/network).
